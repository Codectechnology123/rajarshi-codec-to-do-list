# Rajarshi Codec To-Do List

An advanced MERN To-Do List application built with React, Express, Node.js, and MongoDB. Features include JWT authentication, task CRUD, task status workflow, server-side validation, structured API errors, filtering, sorting, and pagination.

## Project setup

See `backend/README.md` and `frontend/README.md` for setup instructions. Copy each `.env.example` to `.env` and set your own values before running locally.

## Technology

- React + Vite
- Node.js + Express
- MongoDB + Mongoose
- JWT authentication
- REST API

## Security

Never commit `.env` files or production secrets. Use a strong `JWT_SECRET` and a trusted MongoDB connection string in deployment settings.

## Run locally

1. Start MongoDB.
2. Follow `backend/README.md` to start the API.
3. Follow `frontend/README.md` to start the React app.

This project is intended for learning and demonstration. Review configuration and security before production use.
